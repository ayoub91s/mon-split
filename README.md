# Mon Split V8

Déployer `index.html`, `mobility-photos.json` et le dossier `photos/` sur GitHub Pages.

## Photos synchronisées
Le fichier `mobility-photos.json` est partagé sur tous les appareils via GitHub Pages. Exemple :

```json
{
  "m0": "./photos/halo-disque.jpg",
  "m1": "./photos/pass-through.jpg"
}
```

Place les vraies photos dans `photos/` et ajoute les correspondances dans le JSON. Tous les appareils verront les mêmes images après publication GitHub. Les photos importées dans le navigateur restent uniquement locales et servent de solution provisoire. Les favoris, coches et charges restent également locaux.

Sur J3 et J7, une section visible « Repos actif » donne accès aux exercices.
